# 0010. `PROYECTO.md` del Guardián + ejemplo para proyectos nuevos

- **Fecha:** 2026-10-04
- **Estado:** Aceptada

## Contexto

La plantilla debe traer un `PROYECTO.md` de ejemplo, pero el repo ya tiene el alcance del propio Guardián.

## Decisión

`PROYECTO.md` es el del Guardián. La plantilla trae `docs/PROYECTO.ejemplo.md`; un proyecto nuevo lo copia sobre `PROYECTO.md`.

## Por qué

El Guardián se construye con sus propias reglas y necesita su alcance en la raíz.
