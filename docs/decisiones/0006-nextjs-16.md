# 0006. Next.js 16 + TypeScript como base

- **Fecha:** 2026-10-04
- **Estado:** Aceptada

## Contexto

Cada proyecto creado con la plantilla necesita un framework base.

## Decisión

Next.js 16 (línea Active LTS, última estable al crear la plantilla) + TypeScript.

## Por qué

Versión con soporte activo, conocida por el dueño y desplegable en Netlify.
